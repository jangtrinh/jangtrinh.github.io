Overview

This directory holds 26 WebP marks. 20 are original marks generated for design:os on 2026-11-02
(Asia/Saigon). Each one is a 1:1 sculptural 3D clay render of one chunky primitive form, made with
an image generator. The six older hub logos were a style reference only. No third-party brand mark,
logo or likeness was used as the subject or as a reference. Each file was downscaled to 256x256 WebP.
tests/marks.sha256 lists the sha256 of all 26 files, the 20 new marks and the six older ones.
scripts/check-ecosystem.mjs enforces that list. Jang accepted this set on 2026-11-02.
design-os-robotics.webp was added on 2026-11-03 at Jang's request, for the DESIGN:OS Robotics
repo's brand assets: a Design original made the same way as the other 19 (a 1:1 clay-style
render of one chunky primitive form, downscaled to 256x256 WebP); it is not part of the set
accepted on 2026-11-02.
mcp-bridge-go now uses its mark, mcp-bridge-go.webp.

The six older logos (open question O-1)

What these files are
  Six older WebP files: five are 256x256 and design-os-studio.webp is 384x384 (so it is not
  upscaled on 2x screens at its 136px display size). Each is a plain Lanczos downscale plus
  WebP encode (the Studio one: quality 85, method 6; the others' encoder settings were not
  recorded) of a source PNG. Nothing was redrawn, recoloured or generated. There are no SVG
  originals; every source is a raster 3D render, so svgo does not apply.

Usage rights: UNCONFIRMED. Jang has not yet confirmed that he owns these renders or may
  use them as DESIGN:OS brand logos. See attribution below. Jang approved merging
  with this still open (2026-11-02); the rights question stays open and nothing here claims
  the six are original.

  Assigned to repos in a draft mapping that Jang has not approved. Added on branch
  favicon-from-logo on 2026-10-26. The CLI one is on main via design-os #352. The other
  five are on that branch and in open PRs Studio #1214, Bridge #195, SVG Animation #22,
  Code2Flow #2, 3D Blender #32.

Attribution

  ("Nixx Icon 3D", Blender Cycles renders dated 2023). The source files other than the one
  with embedded metadata carry no embedded source text; their consecutive numeric filenames
  (8441427 to 8441441) and identical render style suggest the same kind of pack, but that is
  not proven. No licence, receipt or purchase record was found. This is part of open
  question O-1.
