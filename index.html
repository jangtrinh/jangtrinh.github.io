DESIGN:OS

FREE design tools for AI coding agents (Claude Code, Codex, Cursor, Antigravity).

Every product is free and source-available (PolyForm Shield).

  • DESIGN:OS Studio

    Native GPU-accelerated interface design studio built in Rust, with an MCP server and Dev Mode code output. Reads and writes .fig files.

    GitHubDocs

  • DESIGN:OS CLI

    Design CLI for Claude Code, Codex and Antigravity: describe the UI in plain words and get production-grade web, SwiftUI and Figma-compatible output, checked by deterministic gates.

    GitHubDocs

  • DESIGN:OS Bridge

    Plugin and CLI that lets Claude Code, Codex or any shell agent read and edit the design file you have open. Works with Figma, including the Free plan. Local WebSocket, one undo step per change, no seat.

    GitHubDocs

  • mcp-bridge-go

    Go MCP server (stdio) that sends a prompt to an Electron-based AI IDE on macOS (Antigravity, Cursor, Windsurf) and returns the workspace git diff.

    GitHub

  • DESIGN:OS SVG Animation

    Deterministic vector animation and 1080p 60fps video pipeline for AI coding agents, with a Motion IR compiler and verification gates.

    GitHubDocs

  • DESIGN:OS Code2Flow

    Local CLI that turns a Next.js, React Router, Expo, SwiftUI, Flutter or Compose codebase into user-flow maps and a UX gap report.

    GitHubDocs

  • DESIGN:OS 3D Blender

    AI agent system for Blender 5.2: agent skills, verified bpy knowledge base, execution contract and a production gate for 3D-printable parts. On the official MCP Registry.

    GitHubDocs
